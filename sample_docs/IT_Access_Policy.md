# IT Access & Provisioning Policy

## 1. System Access Approval
All employee system access requests must receive written approval from the department manager prior to provisioning [REF-SEC-01]. IT administrators are strictly prohibited from provisioning credentials without this authorization.

## 2. Multi-Factor Authentication
Multi-Factor Authentication (MFA) is mandatory for all internal and remote access to banking systems [REF-SEC-02]. Hardware security keys or approved authenticator apps must be registered during onboarding.

## 3. Credential Lifecycle & Expiration
All passwords and temporary access tokens must expire every 90 calendar days [REF-SEC-03]. Passwords must have a minimum length of 16 characters and contain upper, lower, numeric, and special symbols.
