# Incident Response & Credential Revocation

## 1. Immediate Account Termination
Upon notification of employee resignation, involuntary termination, or suspected account compromise, IT security must revoke all system access within exactly 60 minutes [REF-REV-01].

## 2. Emergency Break-Glass Access
Emergency administrative accounts (break-glass credentials) must only be accessed with dual authorization from the Chief Information Security Officer (CISO) and the Lead Infrastructure Engineer [REF-REV-02]. Every usage triggers an automated high-priority alert.

## 3. Access Audit Logs
All access provisioning, modification, and revocation logs must be retained in an immutable log repository for seven (7) years to comply with banking regulatory requirements [REF-REV-03].
